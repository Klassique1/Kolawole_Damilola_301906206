# LMS Final Documentation Blueprint (2–3 Pages)

Use this blueprint to produce your final **2–3 page PDF/DOCX submission** for the MIT 8103 LMS portal.

---

## Required Content (MIT 8103 Sections 4, 6, 8, 11 & 12)

1. **Header & Repository Access**
   - Course: `MIT 8103 Advanced Database Systems` (2026/2027 First Semester CA)
   - Student Name & Matriculation Number
   - Private GitHub Repository URL *(confirm assessor collaborator access is active before submitting)*
2. **Selected Case Study / Organisation Statement**
   - Organisation name, business nature, database users, major data stored, and key supported operations (sourced from `case_study.json` / root `README.md`).
3. **Summary of Portfolio Activities (1 through 5)**
   - **Portfolio 1:** Normalisation choices (3NF/BCNF), key constraints, and ER diagram screenshot.
   - **Portfolio 2:** Key queries, indexing strategy, `EXPLAIN (ANALYZE, BUFFERS)` before/after comparison metrics, and execution plan screenshot.
   - **Portfolio 3:** Atomic `COMMIT`/`ROLLBACK` workflow, concurrency hazard reproduced, and locking/isolation control screenshot/log.
   - **Portfolio 4:** MongoDB document schema rationale, aggregation/index results, and suitability vs. PostgreSQL.
   - **Portfolio 5:** Partitioning/replication/sharding architecture, CAP trade-offs, and deployment/simulation evidence.
4. **Individual Technical Reflection**
   - Key design decisions, technical challenges encountered, debugging steps, and lessons learned.
5. **References & AI Use Declaration**
   - Proper citations (PostgreSQL docs, MongoDB docs, textbooks/papers) + summary from [AI_USE_DECLARATION.md](AI_USE_DECLARATION.md).
